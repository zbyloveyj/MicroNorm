# MicroNorm

MicroNorm is a research preview for exploring microbiome profiles against aggregated reference data.

**[Open the online application](https://micronorm-atlas.lemony-fern-4058.chatgpt.site)**

The application runs sample processing locally in your browser. This repository contains the web application and aggregated reference model; it does not contain the underlying individual sample profiles.

The current model is a research preview, not a clinical diagnostic device. See [model-card.txt](model-card.txt) for model scope and limitations.

To use locally, serve the repository as a static website and open `index.html`.
